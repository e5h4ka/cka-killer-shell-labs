# Полная матрица задач

Все строки имеют статус **спроектировано; не реализовано; на кластере не проверено**. «Да» означает оценку технической воспроизводимости, а не результат теста.

Общие требования: свежий kubeadm playground, административный kubectl, доступные образы; для host-операций root/SSH. Узлы cka* заменяются обнаруженными controlplane/worker. Исходные namespaces и пути /opt/course сохраняются, один вопрос активен одновременно. cleanup удаляет только собственные ресурсы; особенности указаны отдельно. Зависимостей от прохождения других вопросов нет: setup каждого создаёт необходимые предпосылки.

## Поперечные правила проверки

Ресурсы ученика оцениваются по семантике, допустимые альтернативы не отклоняются из-за порядка YAML. Финальное состояние не доказывает способ выполнения: для промежуточных действий нужны checkpoints. Отсутствие доказательства означает BLOCKED/неподтверждённый этап, не автоматически PASS. Для каждого вопроса в реализации будет отдельная запись mapping source → adaptation → validation assertions, включая все подпункты данной таблицы.
